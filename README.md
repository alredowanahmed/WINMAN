# Wingman Bro

> The AI Wingman for Tinder, Bumble & Hinge. Get witty replies, openers, and screenshot advice with your personal dating conversation assistant.

---

## Overview

**Wingman Bro** is an AI dating conversation assistant designed to help singles craft witty, calibrated, and authentic text replies for Tinder, Bumble, Hinge, and Instagram DMs.

- **11 Conversation Vibes**: Rizz, Magnetic, Smooth, Witty, Playful, Funny, Flirty, Confident, Casual, Charming, and Direct.
- **Vision & Screenshot OCR**: Upload conversation screenshots or snap a photo for contextual banter advice.
- **Local Privacy**: 100% client-side history stored locally via IndexedDB.
- **Progressive Web App**: Fast, mobile-first responsive design.

---

## Tech Stack

- **Framework**: Angular (Zoneless, OnPush change detection)
- **Styling**: Tailwind CSS
- **AI Engine**: Google Gemini API via `@google/genai`
- **Deployment**: Vercel
